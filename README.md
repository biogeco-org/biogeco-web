# BioGeCo website preview

A responsive static website prototype for the Colombia–Germany BioGeCo research network.

**Status:** Preview; the institutional content and the team information are awaiting confirmation. The current official website remains at https://biogeco.org/.

## Files

- `index.html` — English-language content and page structure.
- `style.css` — responsive layout and visual style.
- `.nojekyll` — ensures straightforward GitHub Pages serving.

## Preview locally

Open `index.html` in a browser, or use **Live Server** in Visual Studio Code.

## Publish on GitHub Pages

Repository: https://github.com/biogeco-org/biogeco-web

1. Push the `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, **main**, and **/(root)**, then save.
4. Check https://biogeco-org.github.io/biogeco-web/ after deployment.
